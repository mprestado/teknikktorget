# TeknikkTorget

A Human–Computer Interaction coursework project demonstrating an e-commerce interface with structured product discovery and accessibility controls.

**Stack:** Bootstrap 5.3, vanilla JavaScript, custom CSS, Material Symbols, and Work Sans.

This repository is a fork of [J4ve/teknikktorget](https://github.com/J4ve/teknikktorget). Project features describe the shared codebase and do not imply sole authorship.

## Explore the interface

- Homepage with onboarding and product discovery
- Catalog, product details, cart, and checkout pages
- Accessibility preferences and Retro Mode
- Client-side interactions and validation

## Run locally

```bash
git clone https://github.com/mprestado/teknikktorget.git
cd teknikktorget
python -m http.server 8000
```

Open http://localhost:8000. No build step or backend is required. CDN styles and fonts need internet access.
